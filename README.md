# Авто Сканер

Мобильное приложение (iPhone и Android) для чтения данных машины через OBD2-адаптер
с Bluetooth LE (проверено с расчётом на Vgate iCar Pro BLE 4.0 / ELM327).

## Что умеет (версия 1)
- Находит адаптер по Bluetooth и подключается к нему.
- Сам определяет протокол машины (CAN, K-line и т.д.) и какие датчики она поддерживает.
- Показывает датчики в реальном времени: обороты, скорость, температуры, нагрузка и др.
- Читает ошибки Check Engine (сохранённые и ожидающие) с расшифровкой на русском.
- Показывает VIN и протокол связи.
- Журнал всех команд, которым можно поделиться (для отладки).
- Демо-режим без машины.

Приложение только читает данные и ничего не меняет в блоках машины.

## Устройство кода
- `src/obd/` — работа с адаптером ELM327: команды, разбор ответов, датчики, ошибки, демо-машина.
- `src/ble/` — подключение по Bluetooth LE.
- `src/ui/` — экраны.
- `tests/` — тесты логики OBD (`npm test`).

## Как собрать
Нужна сборка с нативным модулем Bluetooth (Expo Go не подойдёт).
```
npm install
npm test
npx eas-cli@latest build --platform android --profile preview   # APK для Android
npx eas-cli@latest build --platform ios                          # для TestFlight, нужен Apple Developer
```
## Веб-версия (бесплатный тест на iPhone)
Каждый push в `main` собирает веб-версию и выкладывает её на GitHub Pages.
На iPhone её нужно открывать в бесплатном браузере **Bluefy** (он умеет Bluetooth),
на Android — в Chrome. Адрес задаётся `experiments.baseUrl` в `app.json`
и должен совпадать с названием репозитория.
